## 📌 Overview
**Prisma** is designed to provide a comprehensive, maintainable, and scalable solution in the **Database / ORM** domain. Engineered with modern industry standards and clean architecture.

## ✨ Key Features
- **Type-Safe Queries**: Auto-generated TypeScript client models
- **Relational Modeling**: One-to-one, one-to-many, and many-to-many relationships
- **Migration Management**: Version-controlled database schema migrations

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Edge, Firefox, Safari)

### Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/WEB-TechWhiz/Prisma.git
   cd Prisma
   ```

2. **Run locally:**
   - Open `index.html` directly in your browser or run a local static server:
   ```bash
   npx serve .
   ```
